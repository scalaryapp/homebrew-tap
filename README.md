# scalaryapp/homebrew-tap

Homebrew tap for the [Scalary](https://scalary.com) CLI.

## Install

```sh
brew install scalaryapp/tap/scy
```

The fully-qualified name (`scalaryapp/tap/scy`) auto-taps this repo and, on
Homebrew 6+, trusts just this formula — no separate `brew tap` / `brew trust`
step needed. To update: `brew upgrade scalaryapp/tap/scy`.

The `scy` formula is regenerated automatically by the `scalaryapp/cli` release
workflow on each release — do not hand-edit `Formula/scy.rb`.
